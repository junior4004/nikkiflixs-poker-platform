# RNG Certification Path

## What the platform uses

All card shuffling and game-outcome randomness uses **Node.js `crypto.randomInt` /
`crypto.randomBytes`** — the operating system's cryptographically secure
pseudorandom number generator (CSPRNG):

- Linux: `getrandom(2)` (ChaCha20-based CRNG)
- Windows: BCryptGenRandom
- macOS: CCRandomGenerateBytes

Shuffles are Fisher–Yates with `randomInt(i + 1)` per swap — uniform, no
modulo bias. `Math.random` is never used for game outcomes (it remains
only in cosmetic paths: bot persona selection, banter timing).

Relevant code:
- `server/rng.js` — `cryptoShuffle`, `randInt`, `randomHex`
- `server/engine/deck.js` — platform 8-player engine shuffle
- `server/freetable/game/deck.js` — free-table engine shuffle

## What certification means

For **social / gold-coins-only** operation, no certification is required.
The CSPRNG above exceeds the statistical quality bar.

For **real-money** operation, regulators require an independent lab to
certify the RNG. The three recognized labs:

| Lab | Typical cost | Timeline |
|---|---|---|
| iTech Labs | $15,000–$25,000 | 4–8 weeks |
| GLI (Gaming Laboratories International) | $20,000–$35,000 | 6–10 weeks |
| BMM Testlabs | $15,000–$30,000 | 4–8 weeks |

## Certification steps for the buyer

1. **Freeze the RNG code.** Tag the exact commit of `server/rng.js`,
   `server/engine/deck.js`, and `server/freetable/game/deck.js`.
2. **Provide source access.** Labs review source under NDA, then run
   statistical test suites (Chi-squared, Diehard/Dieharder, NIST SP 800-22)
   against large shuffle samples generated by YOUR deployment.
3. **Generate sample data.** The platform can emit raw shuffle output:
   set `RNG_AUDIT=1` to log deck orders (hex) to `rng-audit.log`
   for the lab's sample set. (Implement the logger before applying.)
4. **Receive certificate.** The lab issues a certificate naming the exact
   code version. Any later change to RNG code voids it — recertify.
5. **Jurisdiction licensing.** RNG certification is one piece; the
   operator still needs the appropriate gaming license per jurisdiction.

## What NOT to do

- Never replace `crypto.randomInt` with `Math.random` "for performance."
- Never seed the shuffle from timestamps, PIDs, or player input.
- Never let client-side code influence the shuffle.

## Vendor note

The vendor (licensor) sells the platform as **gold-coins-only software**.
RNG certification is the **operator's** responsibility and cost when
pursuing real-money licensure. The code is written to be certifiable:
single choke point (`server/rng.js`), no hidden entropy sources.
